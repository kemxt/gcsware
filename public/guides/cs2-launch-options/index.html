CS2 launch options: how to set them and which ones actually help

Whether your launch options box is empty or full of copied tweaks, this guide shows how to set CS2 launch options in Steam, which few are worth keeping and how to test them.

Updated November 8, 20268 min read

Quick answer

  1. In Steam, right-click Counter-Strike 2 in your Library and open Properties → General → Launch Options.
  2. Keep the line short. For most players +exec autoexec (if you use an autoexec) is enough, and an empty box is perfectly fine.
  3. Add -fullscreen, -w/-h or -refresh only if the game starts with the wrong display mode, resolution or refresh rate.
  4. Treat -high and -vulkan as experiments: test one at a time and keep them only if the game clearly runs better.
  5. Remove CS:GO leftovers such as -novid, -tickrate, -threads and old network commands like cl_interp.
  6. When something breaks, clear the box completely and add options back one by one.

How to set launch options in Steam

Launch options are extra instructions Steam passes to CS2 every time the game starts. You add them in one place:

  1. Open Steam and go to your Library.
  2. Right-click Counter-Strike 2 and choose Properties.
  3. On the General tab, find the Launch Options field.
  4. Type your options on one line, separated by spaces, for example -console +exec autoexec.
  5. Close the Properties window and start the game. Launch options only apply when the game launches, so restart CS2 if it was already running.

You will see two kinds of entries in launch options:

  • Dash (-): a startup switch for the game itself, such as -fullscreen or -console.
  • Plus (+): a console command that runs when the game starts, such as +exec autoexec or +fps_max 0.

Spelling matters. A missing dash or a stray character can stop an option from working, so check the whole line after you paste it.

A recommended minimal set

CS2 does not need a long list of launch options to run well. Most "FPS boost" lists you find online are CS:GO leftovers, and display settings are usually handled fine by the in-game menu. If you want more frames, the video settings are the place to start, and our best CS2 settings guide walks through them one by one.

A sensible starting point for most players looks like this:

+exec autoexec

That runs your autoexec.cfg on every launch. If you don't use an autoexec, leaving the box empty is a perfectly good setup. Add the following only when you have a reason:

  • -console if you want the developer console open as soon as the game starts.
  • -nojoy if you never use a controller. It disables controller support, which is a tiny saving at best.
  • -fullscreen plus a forced resolution and refresh rate if CS2 keeps starting with the wrong display settings.

A typical complete line for a mouse and keyboard player with an autoexec could be:

-console -nojoy +exec autoexec

That's it. Everything else is optional, situational or outdated, as the next sections show.

Launch options worth knowing

These are the options that actually do something in CS2. The last column tells you whether each one belongs in a normal setup.

OptionWhat it doesUse it?
+exec autoexecRuns your autoexec.cfg from the cfg folder at launch.Yes, if you use an autoexec.
-consoleOpens the developer console when the game starts.Optional. Handy if you use the console a lot.
-nojoyDisables controller support.Optional. A tiny saving if you never use a controller.
-highRaises the priority of the CS2 process in Windows.Optional, test it. Results are mixed; it can help when background apps keep your CPU busy.
-vulkanUses the Vulkan renderer instead of the default DirectX 11 on Windows.Test it. Results vary by system, so compare both.
-fullscreenForces fullscreen display mode.Usually not needed. Pick Fullscreen as the Display Mode in the video menu.

Before you add -refresh, open Settings → Video and check the refresh rate. People often leave it at 60 Hz by accident, and setting your monitor's maximum there is usually all you need.

Options to remove: CS:GO leftovers

Many "best launch options" lists were written for CS:GO and copied forward ever since. In CS2 the entries below either do nothing useful or make things worse:

  • -novid: skips the intro video. CS2 has no intro video to skip, so it's harmless but pointless.
  • -tickrate 128: CS2 runs on Source 2 with subtick, and official servers run at 64 tick. This option does nothing useful in CS2.
  • -threads followed by a number: don't use it. The engine picks its own thread count, and a wrong value hurts performance.
  • +cl_updaterate, +cl_cmdrate, +cl_interp and +cl_interp_ratio: CS:GO-era network commands that do nothing useful in CS2.
  • +rate 786432: not harmful, but rate already defaults to that maximum, so it adds nothing.

If your launch options contain -threads, delete it now. The engine handles threading on its own, and the wrong thread count can lower your performance.

If a video or forum post recommends an option that isn't in the table above and nobody explains what it does in CS2 specifically, be skeptical and leave it out. A short line is much easier to troubleshoot than a long one.

Launch options or autoexec?

A lot of what people cram into launch options belongs in an autoexec instead. A simple rule:

  • Launch options: startup switches that change how the game starts, such as the renderer, display mode or process priority.
  • Autoexec: console settings like sensitivity, crosshair commands, fps_max and your binds.

A single +exec autoexec in your launch options connects the two. The game runs your file every time it starts, so the launch line stays short and everything else lives in one readable file with comments. The file goes in:

C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\

Yes, the folder kept the CS:GO name. Turn on file name extensions in File Explorer so the file is really autoexec.cfg and not autoexec.cfg.txt. CS2 also saves your settings to Steam Cloud and its own config files, so an autoexec is mainly about a portable, repeatable setup for a new PC, a reinstall or a settings reset. Our CS2 autoexec guide shows how to create the file and what to put in it.

How to test whether an option helps

Options like -high and -vulkan help on some systems and do nothing, or worse, on others. The only way to know is to test them on your own PC.

  1. Turn on the frame rate readout in Settings → Game → Telemetry and set it to show always. While you're there, enable Settings → Game → Enable Developer Console (~) so you can open the console with ~.
  2. Play a baseline session with your current launch options. Use the same map, the same spot and the same video settings, and note the frame rate you typically see and how smooth it feels.
  3. Change one thing only: add or remove a single option.
  4. Restart CS2 and repeat the same session on the same map.
  5. Compare. Keep the option only if the difference is clear and repeatable. If you can't tell, remove it: fewer options means fewer things to go wrong.

For -vulkan, do one run with the option and one without, since you are comparing two renderers rather than a small tweak.

What can skew your results

  • Shader rebuilds. After a driver or game update, the first match can stutter while shaders rebuild. That settles after a match or two, so don't judge an option right after an update.
  • Background apps. A browser playing video, overlays or RGB and monitoring tools can change your frame rate between runs. Close them for both tests.
  • Frame rate vs. smoothness. A higher number is not automatically better. An uncapped or very high frame rate can make frame times uneven on some systems, and a stable fps_max cap you can actually hold often feels smoother.

If your frame rate looks fine but the game still hitches, look beyond launch options. The CS2 stutter guide covers drivers, shader cache, Windows settings and background apps.

Removing options to troubleshoot

If CS2 starts acting up right after you changed launch options (it crashes at startup, opens at the wrong resolution or runs worse than before), rule the launch options out first:

  1. Open Properties → General → Launch Options for Counter-Strike 2.
  2. Copy the whole line into a text file so you can restore it later.
  3. Delete everything in the field so it is completely empty.
  4. Launch CS2 and check whether the problem is gone.
  5. If it is, add your options back one at a time, restarting between each, until the problem returns. The last option you added is the culprit.

If the game opens at the wrong resolution

If you use forced values like -w, -h, -refresh or -fullscreen, remove them first. Then start the game and set Display Mode, resolution and refresh rate in Settings → Video. Put the forced values back only if CS2 keeps launching into a broken resolution.

If an empty box doesn't fix it

  • Remember that +exec autoexec also runs your config file. Leave it out for one test launch to rule out a bad command in your autoexec.
  • Verify the game files: Properties → Installed Files → Verify integrity of game files.
  • Check the usual performance suspects (GPU drivers, shader cache, Windows power mode, background apps) with the steps in the stutter guide.
