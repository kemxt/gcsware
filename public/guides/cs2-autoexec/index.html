CS2 autoexec guide: where it goes, how to make one and a starter config

For anyone who wants their CS2 sensitivity, crosshair and binds in one file they can reuse on any PC. You get the exact folder, step-by-step setup, a commented starter autoexec and fixes for when it doesn't load.

Quick answer

  1. Turn on file name extensions in File Explorer so Windows can't hide a .txt ending.
  2. Go to C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\.
  3. Create a plain text file named exactly autoexec.cfg.
  4. Add one command per line, use // for comments and end the file with echo "autoexec loaded".
  5. In Steam, add +exec autoexec to the CS2 launch options.
  6. Launch CS2, open the console with ~ and look for autoexec loaded.

What an autoexec does

An autoexec is a plain text file, autoexec.cfg, full of console commands. When CS2 runs it, every line is applied as if you had typed it into the developer console yourself: sensitivity, crosshair, viewmodel, radar, binds and so on.

CS2 already saves your settings to Steam Cloud and its own config files, so why bother? Because an autoexec gives you a portable, repeatable setup that you control line by line:

  • New PC or reinstall: copy one file, add one launch option, and your whole setup is back.
  • Settings reset: if something gets reset or you mess up a menu, the next launch puts your values back.
  • Easier as text: buy binds, a mouse wheel jump and exact crosshair or viewmodel values are quicker to manage in a file than through menus.

It doesn't replace the in-game menus. Use the menus to find what you like (our best CS2 settings guide covers video, audio and game options), then lock the values you care about into the file.

Where autoexec.cfg goes

On a default Steam install, the CS2 autoexec location is:

C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\

Yes, the folder still carries the old CS:GO name, which sends a lot of people to the wrong place. The part that matters is game\csgo\cfg\: that's where the game's config files live, and where your autoexec goes.

If your Steam library is on another drive, only the start of the path changes. The quickest way there: in your Steam Library, right-click Counter-Strike 2 → Manage → Browse local files, then open game\csgo\cfg\.

Old CS:GO tutorials point to a cfg folder without game\ in the path. For CS2, always use game\csgo\cfg\.

Create the file step by step

The most common reason an autoexec "doesn't work" is that Windows saved it as autoexec.cfg.txt. File Explorer hides known extensions by default, so the name looks right while the real file type is wrong. Fix that first:

  1. Show file name extensions. In File Explorer, open the View tab and tick File name extensions (on Windows 11: View → Show → File name extensions).
  2. Open the cfg folder from the previous section.
  3. Create the file. Right-click an empty spot → New → Text Document, then rename New Text Document.txt to autoexec.cfg. When Windows warns about changing the extension, click Yes.
  4. Open it in Notepad (right-click → Open with → Notepad), add your commands and save with Ctrl+S.

Starting in Notepad instead? Use File → Save as, set Save as type to All files and type autoexec.cfg as the name, or Notepad adds .txt for you.

Two rules for the contents: one command per line, and comments start with //. Everything after // on a line is ignored, so use comments to note what a value does.

Make it run every launch

Add the file to your launch options so it runs every time you start the game:

  1. In your Steam Library, right-click Counter-Strike 2 → Properties → General.
  2. In Launch Options, add +exec autoexec. Separate it from any other options with a space.
  3. Close the window. Steam saves the change on its own.

You don't need to type .cfg: +exec autoexec finds autoexec.cfg in the cfg folder. Keep the rest of your launch options minimal, since most "FPS boost" lists online are CS:GO leftovers. Our CS2 launch options guide explains which ones are still worth using.

Want to test changes without restarting? Enable the console in Settings → Game → Enable Developer Console (~), press ~ and type exec autoexec. The file runs again right away.

A starter autoexec to copy

Here is a commented starter file. Every number is an example value: put in your own sensitivity, crosshair and viewmodel, and delete any line you don't want. Anything you leave out keeps the value the game already has.

// CS2 autoexec.cfg: all values are EXAMPLES, adjust them

// ---- Mouse ----
sensitivity 1.25
// sensitivity while scoped, relative to normal
zoom_sensitivity_ratio 1

// ---- FPS ----
// pick a cap your PC can hold steadily, 0 = uncapped
fps_max 400
// FPS cap in menus
fps_max_ui 120

// ---- Crosshair ----
cl_crosshairstyle 4
cl_crosshairsize 2
cl_crosshairgap -2
cl_crosshairthickness 1
cl_crosshairdot 0
cl_crosshair_drawoutline 1
cl_crosshair_outlinethickness 1
// 5 = custom color from the r/g/b values below
cl_crosshaircolor 5
cl_crosshaircolor_r 0
cl_crosshaircolor_g 255
cl_crosshaircolor_b 0

// ---- Viewmodel ----
// accepts 54 to 68
viewmodel_fov 68
viewmodel_offset_x 2
viewmodel_offset_y 0
viewmodel_offset_z -1.5
// 1 = right hand, 0 = left hand
cl_righthand 1

// ---- Radar and HUD ----
// lower values show more of the map
cl_radar_scale 0.4
// size of the radar on screen
cl_hud_radar_scale 1.15
// 0 = not locked to the center on you
cl_radar_always_centered 0
// 1 = rotates with your view
cl_radar_rotate 1
// 1 = keep your loadout on screen
cl_showloadout 1
// 0 = no game instructor hints
gameinstructor_enable 0

// ---- Buy binds (numpad) ----
bind "kp_end" "buy ak47; buy m4a1"
bind "kp_downarrow" "buy awp"
bind "kp_pgdn" "buy vesthelm; buy defuser"
bind "kp_leftarrow" "buy smokegrenade"
bind "kp_5" "buy flashbang"

// ---- Utility binds ----
bind "mwheeldown" "+jump"
bind "mouse4" "+voicerecord"

// ---- Save settings and confirm ----
host_writeconfig
echo "autoexec loaded"

A few notes on the values:

  • Mouse: CS2 always uses raw input and has no mouse acceleration options, and Windows Enhance pointer precision doesn't affect your aim in game.
  • FPS cap: fps_max 0 means uncapped. An uncapped or very high frame rate can make frame times uneven on some systems, so a stable cap your PC can actually hold often feels smoother. If you're fighting hitches, see how to fix CS2 stutter.
  • Crosshair: tune it in game first, then copy the values over. Typing a command name alone in the console, such as cl_crosshairsize, shows its current value. You can also share or import crosshair codes in Settings → Game → Crosshair.
  • Viewmodel: prefer a preset? viewmodel_presetpos selects one of the built-in positions.

Useful binds

A bind connects a key to a command: bind "key" "command". To clear a key, use unbind "key". Binds in your autoexec replace whatever that key did before, every time the file runs.

Buy binds

Buy binds save you from clicking through the buy menu every round, and the numpad is a popular spot for them. One key can buy several items if you separate the commands with a semicolon, as in bind "kp_end" "buy ak47; buy m4a1": the same key gets you an AK-47 on T side and an M4 on CT side. Anything your side can't buy, like a defuse kit on T side, is simply not bought.

Key names in configs aren't always obvious:

KeyName in the config
Numpad 1, 2, 3kp_end, kp_downarrow, kp_pgdn
Numpad 4, 5, 6kp_leftarrow, kp_5, kp_rightarrow
Mouse wheel downmwheeldown
Side mouse buttonmouse4

Convenience binds

  • bind "mwheeldown" "+jump": jump on scroll down. It replaces whatever the wheel did before.
  • +voicerecord: push-to-talk. A side mouse button is easy to hold while you move.
  • +lookatweapon: inspects your weapon, if you want it on a different key.

Commands that start with + stay active while you hold the key and stop when you let go. Always put both the key and the command part in quotes, especially when the command contains a semicolon.

Keep it to one movement or attack action per key. Valve restricts scripted binds and aliases that perform several movement or attack actions at once, so they don't work on official servers. Buying several items with one key is fine.

What no longer works in CS2

Many autoexecs floating around were written for CS:GO. Before you paste one in, strip out these lines:

Old CS:GO lineIn CS2
Jump-throw and other multi-action movement aliasesDon't work on official servers
cl_updaterate, cl_cmdrateDo nothing useful
cl_interp, cl_interp_ratioDo nothing useful
rate 786432Already the default
-tickrate (launch option)Does nothing useful
Raw input or mouse acceleration linesNot needed, CS2 always uses raw input

CS2 runs on Source 2 with subtick and official servers run at 64 tick, so tweaking update rates or interpolation won't change anything you can feel. The old movement aliases gave you a perfectly timed jump-throw or a combined action on one key; delete them and do those actions by hand. If an old config also has graphics commands you don't recognize, leave them out and set graphics in the menus.

Troubleshooting and backups

The echo check

After launching CS2, open the console with ~ and scroll through the output. If you see autoexec loaded, the file ran to the end. If it's not there, go through these checks:

  • Launch option: Launch Options must contain +exec autoexec, with the plus sign and a space between exec and autoexec.
  • Hidden .txt extension: with extensions shown, the file must read autoexec.cfg, not autoexec.cfg.txt.
  • Wrong folder: it has to be in ...\Counter-Strike Global Offensive\game\csgo\cfg\. With more than one Steam library, use Manage → Browse local files to be sure you're in the right one.
  • Run it by hand: type exec autoexec in the console. If the console reports a problem with the file, the name or folder is wrong. If it works by hand but not at launch, check the launch option again.

Some lines don't apply

A misspelled command shows an error in the console and is skipped, while the other lines still apply, so read the output right after the file runs. And if a setting keeps changing back, remember that your autoexec applies its values every launch: change the value in the file, not just in the menu.

Back up your autoexec

Keep a copy outside the Steam folder: cloud storage, a USB stick or your notes. Copy it again whenever you change something. On a new PC or after a reinstall, drop the file back into game\csgo\cfg\, add +exec autoexec to the launch options again, and you're done. It's also worth saving your crosshair share code from Settings → Game → Crosshair next to the file.
