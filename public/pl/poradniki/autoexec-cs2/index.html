Autoexec CS2: gdzie go wrzucić, jak go zrobić i gotowy config na start

Dla każdego, kto chce mieć czułość, celownik i bindy w jednym pliku, który przeniesie na każdy komputer. Dostajesz dokładną ścieżkę, instrukcję krok po kroku, startowy autoexec z komentarzami i rozwiązania typowych problemów.

W skrócie

  1. Włącz w Eksploratorze plików pokazywanie rozszerzeń, żeby Windows nie ukrył przed tobą końcówki .txt.
  2. Wejdź do C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\.
  3. Utwórz zwykły plik tekstowy o nazwie dokładnie autoexec.cfg.
  4. Wpisuj jedną komendę w linijce, komentarze zaczynaj od //, a na samym końcu dodaj echo "autoexec wczytany".
  5. W Steamie dopisz +exec autoexec do opcji uruchamiania CS2.
  6. Odpal grę, otwórz konsolę klawiszem ~ i poszukaj napisu autoexec wczytany.

Czym jest autoexec

Autoexec to zwykły plik tekstowy autoexec.cfg z komendami konsoli. Kiedy CS2 go wykonuje, każda linijka działa tak, jakbyś wpisał ją ręcznie w konsoli deweloperskiej: czułość, celownik, viewmodel, radar, bindy i cała reszta.

Skoro CS2 i tak zapisuje ustawienia w Steam Cloud i we własnych plikach konfiguracyjnych, to po co ci autoexec? Bo to twój własny, przenośny config, który za każdym razem ustawia grę tak samo i nad którym masz pełną kontrolę, linijka po linijce:

  • Nowy komputer albo reinstalacja: kopiujesz jeden plik, dodajesz jedną opcję uruchamiania i wszystko jest jak było.
  • Reset ustawień: jeśli coś się wyzeruje albo namieszasz w menu, przy następnym starcie gra wróci do twoich wartości.
  • Wygodniej w tekście: bindy zakupowe, skok na kółku myszy czy dokładne wartości celownika i viewmodelu szybciej ogarniesz w pliku niż w menu.

Autoexec nie zastępuje menu w grze. W menu znajdź to, co ci pasuje (grafikę, dźwięk i opcje gry rozpisaliśmy w poradniku najlepsze ustawienia CS2), a potem zapisz w pliku wartości, na których ci zależy.

Gdzie jest autoexec w CS2

Przy standardowej instalacji Steama autoexec CS2 wrzucasz do folderu:

C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\

Tak, folder gry nadal nosi starą nazwę po CS:GO i przez to sporo osób szuka w złym miejscu. Liczy się końcówka game\csgo\cfg\: tam leżą pliki konfiguracyjne gry i tam ląduje twój autoexec.

Jeśli masz bibliotekę Steama na innym dysku, zmienia się tylko początek ścieżki. Najszybciej trafisz tam ze Steama: w Bibliotece kliknij prawym przyciskiem Counter-Strike 2 → Zarządzaj → Przeglądaj pliki lokalne, a potem wejdź w game\csgo\cfg\.

Stare poradniki do CS:GO pokazują folder cfg bez game\ w ścieżce. W CS2 zawsze używaj game\csgo\cfg\.

Jak zrobić autoexec krok po kroku

Najczęstszy powód, dla którego autoexec „nie działa”, to plik zapisany jako autoexec.cfg.txt. Eksplorator plików domyślnie ukrywa znane rozszerzenia, więc nazwa wygląda dobrze, a typ pliku jest zły. Dlatego zacznij od tego:

  1. Włącz rozszerzenia plików. W Eksploratorze plików otwórz kartę Widok i zaznacz Rozszerzenia nazw plików (w Windows 11: Widok → Pokaż → Rozszerzenia nazw plików).
  2. Otwórz folder cfg z poprzedniej sekcji.
  3. Utwórz plik. Kliknij prawym przyciskiem w puste miejsce → Nowy → Dokument tekstowy i zmień nazwę nowego pliku na autoexec.cfg. Gdy Windows zapyta, czy na pewno zmienić rozszerzenie, kliknij Tak.
  4. Otwórz go w Notatniku (prawy przycisk → Otwórz za pomocą → Notatnik), wklej komendy i zapisz skrótem Ctrl+S.

Wolisz zacząć od Notatnika? Wybierz Plik → Zapisz jako, w polu Zapisz jako typ ustaw Wszystkie pliki i wpisz nazwę autoexec.cfg. Inaczej Notatnik sam doklei .txt.

Dwie zasady dotyczące zawartości: jedna komenda w jednej linijce, a komentarze zaczynają się od //. Gra pomija wszystko, co stoi za // w danej linijce, więc opisuj sobie w komentarzach, co robi dana wartość.

Jak odpalać go przy każdym starcie

Dodaj plik do opcji uruchamiania, żeby gra wykonywała go przy każdym starcie:

  1. W Bibliotece Steama kliknij prawym przyciskiem Counter-Strike 2 → Właściwości → Ogólne.
  2. W polu Opcje uruchamiania dopisz +exec autoexec. Jeśli masz tam już inne opcje, oddziel je spacją.
  3. Zamknij okno. Steam sam zapisze zmianę.

Nie musisz dopisywać .cfg: +exec autoexec sam znajdzie plik autoexec.cfg w folderze cfg. Resztę opcji uruchamiania trzymaj w minimum, bo większość list „FPS boost” z internetu to pozostałości po CS:GO. Które opcje nadal mają sens, opisujemy w poradniku opcje uruchamiania CS2.

Chcesz sprawdzić zmiany bez restartu gry? Włącz konsolę w ustawieniach (Settings → Game → Enable Developer Console (~)), naciśnij ~ i wpisz exec autoexec. Plik wykona się od razu.

Gotowy autoexec na start

Poniżej masz startowy plik z komentarzami. Każda liczba to przykładowa wartość: wpisz swoją czułość, celownik i viewmodel, a linijki, których nie potrzebujesz, po prostu usuń. Czego nie ma w pliku, zostaje tak, jak masz ustawione w grze.

// CS2 autoexec.cfg: wszystkie wartości to PRZYKŁADY, dopasuj je do siebie

// ---- Mysz ----
sensitivity 1.25
// czułość w lunecie względem zwykłej
zoom_sensitivity_ratio 1

// ---- FPS ----
// limit, który twój PC stabilnie utrzyma, 0 = bez limitu
fps_max 400
// limit FPS w menu
fps_max_ui 120

// ---- Celownik ----
cl_crosshairstyle 4
cl_crosshairsize 2
cl_crosshairgap -2
cl_crosshairthickness 1
cl_crosshairdot 0
cl_crosshair_drawoutline 1
cl_crosshair_outlinethickness 1
// 5 = własny kolor z wartości r/g/b poniżej
cl_crosshaircolor 5
cl_crosshaircolor_r 0
cl_crosshaircolor_g 255
cl_crosshaircolor_b 0

// ---- Viewmodel ----
// zakres od 54 do 68
viewmodel_fov 68
viewmodel_offset_x 2
viewmodel_offset_y 0
viewmodel_offset_z -1.5
// 1 = broń w prawej ręce, 0 = w lewej
cl_righthand 1

// ---- Radar i HUD ----
// niższa wartość pokazuje więcej mapy
cl_radar_scale 0.4
// rozmiar radaru na ekranie
cl_hud_radar_scale 1.15
// 0 = radar nie trzyma cię zawsze na środku
cl_radar_always_centered 0
// 1 = radar obraca się razem z widokiem
cl_radar_rotate 1
// 1 = ekwipunek zawsze widoczny na ekranie
cl_showloadout 1
// 0 = bez podpowiedzi samouczka
gameinstructor_enable 0

// ---- Bindy zakupowe (numpad) ----
bind "kp_end" "buy ak47; buy m4a1"
bind "kp_downarrow" "buy awp"
bind "kp_pgdn" "buy vesthelm; buy defuser"
bind "kp_leftarrow" "buy smokegrenade"
bind "kp_5" "buy flashbang"

// ---- Bindy użytkowe ----
bind "mwheeldown" "+jump"
bind "mouse4" "+voicerecord"

// ---- Zapis ustawień i potwierdzenie ----
host_writeconfig
echo "autoexec wczytany"

Kilka uwag do wartości:

  • Mysz: CS2 zawsze korzysta z raw input i nie ma żadnych opcji akceleracji myszy, a windowsowa opcja precyzji wskaźnika (Enhance pointer precision) nie wpływa na celowanie w grze.
  • Limit FPS: fps_max 0 oznacza brak limitu. Bez limitu albo przy bardzo wysokim FPS czasy klatek na niektórych komputerach robią się nierówne, więc stabilny limit, który twój sprzęt naprawdę utrzyma, często daje płynniejszą grę. Jeśli walczysz z przycięciami, zajrzyj do poradnika CS2 przycina i spada FPS.
  • Celownik: ustaw go najpierw w grze, a potem przepisz wartości do pliku. Jeśli wpiszesz w konsoli samą nazwę komendy, np. cl_crosshairsize, zobaczysz jej aktualną wartość. Kodami celownika możesz się też dzielić i importować je w Settings → Game → Crosshair.
  • Viewmodel: wolisz gotowe ustawienie? viewmodel_presetpos wybiera jedną z wbudowanych pozycji broni.

Przydatne bindy

Bind przypisuje komendę do klawisza: bind "klawisz" "komenda". Klawisz czyścisz komendą unbind "klawisz". Bindy z autoexeca nadpisują to, co dany klawisz robił wcześniej, za każdym razem, gdy plik się wykona.

Bindy zakupowe

Bindy zakupowe oszczędzają ci klikania po menu kupowania w każdej rundzie, a numpad to dla nich popularne miejsce. Jeden klawisz może kupić kilka rzeczy, jeśli oddzielisz komendy średnikiem, np. bind "kp_end" "buy ak47; buy m4a1": ten sam klawisz daje ci AK-47 po stronie T i M4 po stronie CT. Jeśli komenda dotyczy czegoś, czego twoja strona nie może kupić (np. zestawu do rozbrajania jako T), po prostu nic nie kupi.

Nazwy klawiszy w configu nie zawsze są oczywiste:

KlawiszNazwa w configu
Numpad 1, 2, 3kp_end, kp_downarrow, kp_pgdn
Numpad 4, 5, 6kp_leftarrow, kp_5, kp_rightarrow
Kółko myszy w dółmwheeldown
Boczny przycisk myszymouse4

Bindy użytkowe

  • bind "mwheeldown" "+jump": skok na kółku w dół. Zastępuje to, co kółko robiło wcześniej.
  • +voicerecord: mówienie na przycisk (push-to-talk). Boczny przycisk myszy łatwo przytrzymać w ruchu.
  • +lookatweapon: oglądanie broni, jeśli chcesz mieć je pod innym klawiszem.

Komendy z plusem na początku działają, dopóki trzymasz klawisz, i wyłączają się, gdy go puścisz. Zawsze bierz w cudzysłów zarówno klawisz, jak i część z komendą, zwłaszcza gdy w komendzie jest średnik.

Trzymaj się zasady: jedna akcja ruchu albo ataku na klawisz. Valve ogranicza skryptowe bindy i aliasy, które wykonują kilka akcji ruchu lub ataku naraz, więc na oficjalnych serwerach nie działają. Kupowanie kilku rzeczy jednym klawiszem jest w porządku.

Co już nie działa w CS2

Mnóstwo autoexeców krążących po sieci powstało jeszcze pod CS:GO. Zanim wkleisz taki plik, wyrzuć z niego te linijki:

Stara linijka z CS:GOW CS2
Jump-throw i inne aliasy łączące kilka akcji ruchuNie działają na oficjalnych serwerach
cl_updaterate, cl_cmdrateNic sensownego nie dają
cl_interp, cl_interp_ratioNic sensownego nie dają
rate 786432To już wartość domyślna
-tickrate (opcja uruchamiania)Nic sensownego nie daje
Linijki od raw input i akceleracji myszyNiepotrzebne, CS2 zawsze używa raw input

CS2 działa na Source 2 z subtickiem, a oficjalne serwery chodzą na 64 tickach, więc grzebanie w update rate czy interpolacji w autoexecu nie zmieni niczego, co poczujesz w grze. Stare aliasy ruchu dawały idealnie zgrany jump-throw albo kilka akcji pod jednym klawiszem. Usuń je i rób te rzeczy ręcznie. Jeśli stary config ma do tego masę komend graficznych, których nie znasz, odpuść je i ustaw grafikę w menu.

Problemy i kopia zapasowa

Test z echo

Po odpaleniu CS2 otwórz konsolę klawiszem ~ i przejrzyj, co się w niej wyświetliło. Jeśli widzisz autoexec wczytany, plik wykonał się do końca. Jeśli napisu nie ma, sprawdź po kolei:

  • Opcja uruchamiania: w polu Opcje uruchamiania musi być +exec autoexec, z plusem i spacją między exec a autoexec.
  • Ukryte rozszerzenie .txt: przy włączonych rozszerzeniach plik musi nazywać się autoexec.cfg, a nie autoexec.cfg.txt.
  • Zły folder: plik musi leżeć w ...\Counter-Strike Global Offensive\game\csgo\cfg\. Jeśli masz kilka bibliotek Steama, użyj Zarządzaj → Przeglądaj pliki lokalne, żeby mieć pewność, że jesteś w tej właściwej.
  • Odpal go ręcznie: wpisz w konsoli exec autoexec. Jeśli konsola zgłasza problem z plikiem, nazwa albo folder są złe. Jeśli ręcznie działa, a przy starcie nie, jeszcze raz sprawdź opcję uruchamiania.

Część linijek nie działa

Komenda z literówką wyświetli w konsoli błąd i zostanie pominięta, a reszta pliku i tak się wykona, więc przejrzyj konsolę zaraz po wczytaniu pliku. A jeśli jakieś ustawienie ciągle wraca do starej wartości, pamiętaj, że autoexec ustawia swoje wartości przy każdym starcie: zmieniaj je w pliku, a nie tylko w menu.

Zrób kopię zapasową

Trzymaj kopię pliku poza folderem Steama: na dysku w chmurze, na pendrivie albo w swoich notatkach. Po każdej zmianie skopiuj go jeszcze raz. Na nowym komputerze albo po reinstalacji wrzuć plik z powrotem do game\csgo\cfg\, dopisz +exec autoexec do opcji uruchamiania i gotowe. Warto też zapisać obok kod swojego celownika z Settings → Game → Crosshair.
